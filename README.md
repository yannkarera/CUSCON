# Bienvenue sur CUSCON, une plateforme e-commerce dédiée à la vente de manettes de jeu personnalisées.
L’objectif de ce projet est d’offrir aux joueurs la possibilité de créer une manette unique qui reflète leur style, tout en bénéficiant d’une expérience d’achat fluide et moderne.

Fonctionnalités

🛒 Catalogue de manettes : parcourez différentes bases de manettes (PS, Xbox, Switch, etc.)

👤 Gestion utilisateur : inscription, connexion

🔍 Recherche et filtres avancés pour trouver facilement vos modèles préférés

🛠️ Stack Technique

Frontend : HTML / Javascript / CSS

Backend : PHP / Javascript

Base de données : MySQL
